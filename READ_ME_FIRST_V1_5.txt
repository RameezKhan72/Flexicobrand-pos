FLEXICO POS v1.5 — FULL SHOPIFY CATALOGUE IMPORT EDITION

This download upgrades your existing POS. Real Shopify website products are not embedded, because the live API export is not available from this development environment. You CAN import every active/published product and variant using a Shopify Products CSV export or connected Shopify Admin API.

QUICKEST METHOD:
1. On Shopify Admin: Products -> Export -> All products -> CSV for Excel/Numbers.
2. Download products_export.csv (do not modify it).
3. Back up your previous POS data folder, close the previous POS, and extract this ZIP to a NEW folder.
4. Copy the previous data folder and public/uploads into this new folder if you have existing data.
5. Double-click start-windows.bat (Node.js 22.13+ required).
6. Log in as Admin -> Website Catalogue -> Choose Shopify CSV -> Preview CSV -> Import All Products from CSV.
7. Review product/variant counts, prices and images; cache photos as needed. All imported new stock starts at zero.

See SHOPIFY_FULL_CATALOGUE_IMPORT_V1_5.md and QA_V1_5.md.
